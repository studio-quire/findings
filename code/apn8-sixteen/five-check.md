# Independent check (search B): can a quadratic APN function on F_2^8 have 5 rank-4 components?

Subagent (Claude Opus 5.5), 2026-11-06, for Rowen. A bounded task: this file, the `fivecheck_*` sources and `runs/check5/`.
Status: **done** (2026-11-06). Verdict in §7: no such function, and none with more than five either.

## 1. Setup, as verified

S8 = {B_b} is an 8-dim space of alternating forms on V = F_2^8 and F is APN iff every a != 0 lies in the radical of
exactly one nonzero B (as `sixteen-check.md` §1; I re-derived it). Counting points, sum over nonzero B of (2^dim rad - 1)
= 255. With n4 = 5 and no rank-2 form: 15*5 + 3*n6 = 255, so n6 = 60, n8 = 190: [0^190, 2^60, 4^5]. The brief's setup is
right. A rank-2 form has a 6-dim radical, which meets any solid, so it can't coexist with a rank-4 form.

**What the search actually covers is wider than the case asked:** it assumes nothing about ranks beyond the five chosen
forms, so it reaches any S8 with *at least* five rank-4 components. Its verdict is a verdict on all of Open Problem VI.1.

## 2. Reduction

Five rank-4 forms have pairwise disjoint radicals, so five pairwise complementary solids. Coordinates V = A + A, A = F_2^4:
R1 = {(x,0)}, R2 = {(0,y)}, R3 = graph(I), R4 = graph(T), R5 = graph(T'), with T, T', T+I, T'+I, T+T' invertible. A form with
radical R_i is d(L_i u, L_i v) for one of the 28 nondegenerate alternating forms d on F_2^4, L_i: V -> F_2^4 with kernel R_i.
So once a class of solids is fixed, the five forms are a tuple in 28^5, **and all 28^5 are run**: no normalisation of the forms, no
symmetry reduction of any kind in the main run. The one reduction is "one representative per GL(8,2)-class of solids".

## 4. Method: why this isn't a search over points

Nothing here branches on a point, or grows the space a form at a time toward an uncovered point. Rowen's block view is used in
this form, one coset at a time rather than one C at a time; see the last paragraph of this section for why.

1. **Forms.** For a class representative, every tuple in 28^r, with a prefix test and a leaf test: S = span(B_i) is kept iff
   no element other than the B_i has a radical point on a solid and all radicals of S are pairwise disjoint. Nothing about the rank
   of any other element. dim S is 5, or 4 when the five forms satisfy a linear relation (it can't be lower: a relation among three
   has M = 0 against an invertible M, and two relations would give one on fewer than four forms).
2. **Block sieve.** S8 = S + T, dim T = 8 - dim S =: e. Every coset t + S of Alt(V)/S (2^23) is tested at once. A coset survives iff
   no form of it has a point of a solid or of S's own radicals in its radical (necessary: a point lies in one radical only; and
   two forms of a coset sharing a point differ by an element of S killing it, so this also gives disjointness inside the coset).
   Equivalently t(a, .) is nonzero on K_a/<a>, K_a = {v : s(a, v) = 0 for all s in S}: e bits per point, packed four to a slot.
   With t = (P, M, Q) on V = R1 + R2, a point of R1 sees only (P, M) and a point of R2 only (Q, M). So the loop is M over
   M_4 / M(S) (2^13), the P-lifts (2^5) sieved on R1 and the Q-lifts (2^5) on R2 *separately*, and only surviving (P, Q) pairs meet
   the other solids. This P/Q decoupling is the block view's useful consequence.
3. **Assembly.** T is an e-dim subspace of the survivors, found by plain subspace search: first element, then elements whose sums
   with the span are survivors with disjoint radicals. For dim S = 4 (e = 4) a weight pivot cuts the first levels: the radicals of T's
   cosets partition what S leaves, so the lightest remaining coset weighs at most rem/(cosets left). The dim-5 main run doesn't use it.
4. **Verification.** Every T found goes through `verifyS8`: all 255 forms, radicals by plain evaluation at every point.

What the earlier searches rest on, as the brief describes it, is branching over points. Here the main test is a sieve over all
forms at once, and the conclusion is reached by a subspace search among forms; points only ever appear in a fixed list that every form
is tested against. The test does still evaluate forms at points. Any correct search has to impose "one radical per point"
somewhere, so that part can't be independent in idea; what's independent is the organisation around it. Say so plainly:
if one wanted a test with no point in it at all, this isn't that.

Enumerating C itself, as the brief suggested, I estimated rather than measured, and dropped on the estimate: about 3*10^7 C's per D pass the rank-distance test
(2^30 raw, a heuristic 3%), over about 5*10^4 D's, so about 10^12 C's each needing lifts. Sieving single cosets gets the same block structure at 2^13 * 2^5 * 2 per S.
The dim K claim is therefore not used. It's proved by hand (below) and tested on what exists.

**Block view, checked.** dim K in {2, 3}: for a = (a1, 0), kernel of B -> B(a, .) on S8 is <B1>, on K that map is P_B(a1, .), so a
nonzero P_B on K/<B1> kills no a1: nondegenerate, an anisotropic subspace of the Klein quadric (Pfaffian, plus type on F_2^6, Witt
index 3, anisotropic dim <= 2). P injective on K/<B1> since P_B = 0 with M = 0 puts all of R1 in rad B. K contains B1, B2. Correct as
Rowen wrote it. The rank-1 claim is correct too. `fivecheck_blockview.py` on the 26 known classes, 312 ordered pairs: dim K = 2 every
time, every claim held.

## 7. Verdict

**No quadratic APN function on F_2^8 has exactly five rank-4 components, and none has more.** Every S8 with at least five rank-4
components would contain five forms whose radicals are five disjoint solids, so it would be, up to GL(8,2), an extension of one of the
29,773,651 admissible sets S in the 22 classes (or an orbit-equivalent of one of the 103 representatives for the 1,641 of dimension 4). None
extends: no T in any of them. So, on this search, Open Problem VI.1 is answered: no. That covers 16 down to 6 as well, independently of
Rowen's cases, as a by-product, since nothing here assumed the count was exactly five.

How sure: the search is exhaustive by construction, and each stage is tested against a definition or a known answer (§6), on the run's source or on later builds that differ from it, on that path, only by checks and debug output. What the verdict leans on: the classification (22, matching Kurz; identities exact), the block sieve's equality with
the definition (samples, not all 29.8M sets; the code is one loop for all of them), the assembly (planted and brute-counted), and the
Gamma reduction for the dimension-4 sets only. It's a computation, without a proof certificate: no DRAT or equivalent, so a reader has to rerun or
trust. The most valuable next step would be search A's agreement, compared stage by stage, for instance the admissible counts per class.
The classification and the admissible sets rest on the same definitions as search A, though coded separately: A's agreement tests the code there, not the idea. [Added by Rowen.]

A thing worth a look, not a finding: planes are rare in general but abundant in classes 20 and 21 (14.8M, 24.5M against about 1M elsewhere),
and 25 of the 26 known four-rank-4 functions sit on the F_4 subline. Class 21 is where a fifth would have been most expected, and it isn't there.
